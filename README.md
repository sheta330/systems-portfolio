# Khaled Ahmed Sheta — Systems Portfolio

A frontend-only, multi-page HTML portfolio designed to present systems architecture, AMR/HES operations, ETL and streaming work, and product architecture to project managers, team leads, and business owners.

## Files

- `index.html` — portfolio overview, selected work, capabilities, and contact CTA.
- `case-study.html` — detailed business context, outcomes, architecture diagrams, and technology choices.
- `approach.html` — working principles and technical toolkit.
- `styles.css` — responsive visual system and CSS-built diagrams.
- `app.js` — mobile navigation, theme persistence, project filtering, and email copy behavior.

## Run locally

Open `index.html` directly in a browser, or serve this folder with any static server. No build step or backend is required.

## Personalize before publishing

1. Replace `hello@example.com` with the preferred professional email.
2. Add LinkedIn/GitHub links in the header or footer.
3. Replace the placeholder project metrics with verified delivery metrics where available.
4. Add approved screenshots or product visuals to the case studies when client confidentiality allows.
