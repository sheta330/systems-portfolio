02

Data & integration platform

Data movement
without blind spots.

The ETL landscape connects meter protocols, network transport, file exchange and enterprise databases. The engineering goal was a dependable path from raw signals to usable records, with observability and recovery treated as product requirements.

Business problem

High-volume integration fails in small, expensive ways: a dropped packet, an unreadable payload, a late file or a silent database mismatch.

What I shaped

Worker services for UDP and Kafka, DLMS decryption/encoding, named pipes and secure file transfer components, with logging, mapping and data-access layers designed to keep failure visible.

Technology

C# · .NET 8 Worker Services · Confluent Kafka · UDP · Gurux DLMS · Oracle · SQL Server · SSH.NET · NLog

Product architecture

Complexity at the edges.

Payments and AI products both suffer when every integration becomes a one-off. WISC focused on a stable core: contracts, strategies and event-driven extension points that let new capability arrive without rewriting the product.
